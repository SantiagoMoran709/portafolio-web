# Portafolio de Santiago Morán

Abrí `index.html` en el navegador. No hace falta instalar nada. Mantené juntos `index.html`, `styles.css`, `motion.js`, `icon.svg`, `assets/` y `demos/`.

- **AtlasFX** abre una compilación de la versión web del editor, incluida en `demos/atlasfx/`.
- **Nexora** y **One Code** abren sus sitios publicados. Necesitan conexión a internet.
- El botón **GitHub** abre el perfil de Santiago Morán.

La portada usa la foto de montaña proporcionada. Las imágenes de Nexora y One Code son capturas de sus sitios; la de AtlasFX proviene de su repositorio. Las animaciones respetan la preferencia de movimiento reducido.
